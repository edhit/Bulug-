# Булюг аль-Марам

Веб-версия сборника хадисов «Булюг аль-Марам» — один самодостаточный HTML-файл:
шрифты, стили, скрипты и весь текст встроены внутрь, внешних запросов нет.
Работает офлайн, настройки и закладки хранятся в `localStorage` браузера.

## Сайт

https://edhit.github.io/Bulug-/

## Как это опубликовано

* `index.html` — само приложение (≈2 МБ).
* `.github/workflows/pages.yml` — деплой на GitHub Pages через GitHub Actions.
* `.nojekyll` — отключает обработку Jekyll.

Перед первым деплоем Pages нужно включить вручную — один раз:
**Settings → Pages → Build and deployment → Source: GitHub Actions**.
Автоматически workflow это сделать не может: создание Pages-сайта требует
прав администратора репозитория, которых у `GITHUB_TOKEN` нет.
После включения каждый push в ветку публикует сайт заново.

## Локальный запуск

Файл открывается напрямую в браузере — сборка не нужна:

```sh
open index.html
```
